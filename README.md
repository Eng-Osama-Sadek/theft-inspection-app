#  منظومة فحص سرقات التيار الكهربائي (V2.0)

تطبيق موبايل متكامل (Offline-first) مخصص لمفتشي شركات توزيع الكهرباء لتسجيل محاضر سرقة التيار الكهربائي وحساب الغرامات بدقة وفقا للوائح التجارية الموحدة لعام 2027.

##  مميزات التطبيق
- **حسابات دقيقة 100%:** مطابق لمعادلات الإكسيل المعتمدة من شركة مصر الوسطى (شرائح 2026/2027 معامل التشتت الدمغة ورسم الإذاعة).
- **تفصيل الأحمال:** تسجيل اسم كل حمل وقدرته بالوات، وإظهار القائمة في تقرير Excel.
- **مطابقة ورقة الحساب:** الكمية = مجموع الأحمال × ساعات التشغيل × الأيام × معامل التشتت ÷ 1000، ثم خصم الكمية المسددة؛ وقيمة التيار = صافي الكمية × سعر النشاط. الإجمالي يجمع قيمة التيار والغرامة ورسوم النشاط، ويضيف غرامة تكرار المخالفة عند اختيار محضر سابق، ثم يُرفع لأقرب جنيه صحيح.
- **متابعة المحاضر:** البحث الفوري بالاسم أو رقم العداد، مع إمكانية جمع البحث والتصفية بتاريخ البداية والنهاية. تعرض الشاشة إجمالي المحاضر والغرامات المحفوظة، وعدد النتائج المطابقة للفلاتر.
- **حفظ موثوق:** تُنسخ الصور والفيديو إلى مساحة التطبيق فور التقاطها لتجنب اختفائها من الكاش المؤقت قبل حفظ المحضر. لا تُعرض رسالة نجاح إلا بعد حفظ التقرير والبيانات، وتظهر رسالة واضحة عند فشل الحفظ. بيانات البحث داخل التطبيق محلية؛ حذف التطبيق قد يحذفها، أما الملفات المصدّرة إلى Download فتبقى في مجلد التنزيلات.
- **توثيق شامل:** تصوير بطاقة الرقم القومي (وش وظهر) وتسجيل فيديو للواقعة مباشرة من التطبيق.
- **إدارة الملفات:** حفظ الصور والفيديو وتقرير Excel معًا في مجلد خاص بكل محضر داخل مجلد Download الذي يختاره المستخدم مرة واحدة. يحتفظ التطبيق أيضًا ببيانات المحاضر محليًا لتشغيل البحث والتصفية.
- **تصميم عصري:** واجهة مستخدم زرقاء متدرجة (Glassmorphism) مريحة للعين ومناسبة للعمل الميداني.
- **يعمل أوفلاين:** لا يحتاج إنترنت لتسجيل الواقعة أو حساب الغرامة.

##  التقنيات المستخدمة
- **Framework:** Flutter (Dart)
- **State Management:** Vanilla State (قابل للترقية)
- **Local Storage:** Path Provider
- **Reporting:** Excel Package
- **Media:** Image Picker
